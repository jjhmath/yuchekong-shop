# 유체콩샵 앱 (애견미용 예약 + 픽업 실시간 추적)

조준호 수학학원 앱(jjh-math)과 **완전히 별개**인 프로젝트입니다. 파이어베이스 프로젝트·저장소·코드를 공유하지 않습니다.

## 화면
- **견주**: 아이 등록(미용 요청서: 민감 부위, 스타일·참고 사진, 몸통 mm·얼굴·다리, 싫어하는 것, 달래는 방법, 간식·알러지) → 예약(동의 체크, 접수 시각 기록) → 진행 상황 → 실시간 위치 → 완료 리포트
- **샵(미용사)**: 오늘/예정/지난 예약, 예약 확정, 작업지시서(알러지 빨간 띠), 요청서 확인 시각 기록, 작업 체크(시각 자동 기록), 미용 전·후 사진, 완료 리포트
- **픽업(매니저)**: 픽업 출발 → 탑승 사진 → 샵 도착 / 귀가 출발 → 인계 사진, 이동 중 휴대폰 GPS를 4초마다 전송

## 근거 기록
- 예약 때 요청서 **사본**이 예약에 고정 저장되고, 견주가 고치면 `revisions`에 이전·이후가 남음 (삭제·수정 불가)
- 사진은 추가만 가능(삭제·수정 불가), 진행 단계마다 서버 시각 기록

## 설정
1. 파이어베이스 콘솔에서 **새 프로젝트** 생성 (예: `yuchekong-shop`) — Spark(무료) 요금제로 충분
2. Authentication → Google 로그인 사용 설정
3. Firestore 데이터베이스 생성 (서울 `asia-northeast3`)
4. 웹 앱 추가 → 나온 설정값을 `docs/config.js`에 붙여 넣기, 샵 좌표·전화번호도 입력
5. `firebase deploy --project <새 프로젝트 ID>`
6. 직원 등록: 미용사·매니저가 한 번 로그인한 뒤, 콘솔 Firestore에 `staff/{그 사람 uid}` 문서를 만들고 `role: "groomer"` 또는 `"driver"` 입력
